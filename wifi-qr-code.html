How to create a Wi-Fi QR code

  1. Open the Wi-Fi tab in the generator.
  2. Enter the network name (SSID) exactly as it appears in the phone's Wi-Fi list.
  3. Pick the security type — WPA/WPA2 for almost every modern router, WEP only for very old equipment, or None for an open network.
  4. Enter the password. It is turned into the pattern inside your own browser and never sent to a server.
  5. Generate, download and test it with a phone that is not already on the network.

The mistakes that stop it working

Capital letters in the network name

SSIDs are case sensitive. "CafeGuest" and "cafeguest" are different networks, and a mismatch fails silently — the phone simply never connects.

Wrong security type

Picking WEP when the router runs WPA2 produces a code that scans fine and then refuses to join. If in doubt, check the router's admin page or the label on its underside.

Testing on a phone already connected

A device that already knows the network will look like a success whatever the code says. Always test on a phone that has never joined, or make it forget the network first.

Printing it too small

A Wi-Fi password makes a denser pattern than a short link. Give it at least 4cm across on a table card, and more if it will sit on a wall.

Where a Wi-Fi code earns its keep

Cafés and restaurants — a small card on each table stops staff reciting the password twenty times a shift. Holiday lets and spare rooms — put it in the welcome folder and guests are online before they have unpacked. Offices and reception areas — a guest network code by the front desk saves interrupting whoever knows the password. Events and venues — print it on the badge or the back of the programme.

Is it safe to put your Wi-Fi password on a wall?

Anyone who can see the code can join the network, exactly as if they had read the password off a whiteboard. That is fine for a network you are happy for visitors to use, and the usual advice applies: put guests on a separate guest network rather than the one your own computers, till system or NAS sit on. Most routers offer a guest network in a couple of clicks.

What does not happen is your password travelling across the internet. The code is built inside your browser, so the password never reaches us or anyone else.
